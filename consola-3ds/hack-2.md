1.  ⚠️𝗖𝗼𝗺𝗽𝗮𝘁𝗶𝗯𝗹𝗲 𝘀𝗼𝗹𝗼 𝗰𝗼𝗻 𝗺𝗼𝗱𝗲𝗹𝗼 𝗢𝗟𝗗 𝗲𝗻 𝘃𝗲𝗿𝘀𝗶𝗼𝗻𝗲𝘀 𝟭.𝟬.𝟬 𝗵𝗮𝘀𝘁𝗮 𝟭𝟭.𝟭𝟰 ⚠️HACK 3DS - SAFECERTHAX**REQUISITOS**

    * Consola Virgen 3ds/2ds OLD en **Versión 1.0 a 11.14**
    * Tarjeta Sd en formato FAT32 de 4 a 32 GB

    𝗣𝘂𝗲𝗱𝗲𝘀 𝘃𝗶𝘀𝘂𝗮𝗹𝗶𝘇𝗮𝗿 𝗻𝘂𝗲𝘀𝘁𝗿𝗼𝘀 𝗽𝗿𝗼𝗱𝘂𝗰𝘁𝗼𝘀 𝗲𝗻 ⁠📒guías-sd

    * Archivos Hack

    **PASO 1. DESCARGAR ARCHIVOS HACK**

    * introducir los archivos en la SD de la Consola

    **PASO 2. MODIFICAR AJUSTES PROXY**

    * Acudir a Configuración de la consola
    * Configuración de Internet / Conexión a Internet.
    * Seleccionamos la Conexión que tengamos (de no tener, hay que conectar una).
    * Seleccionamos Modificar ajustes / Servidor Proxy / Sí / Ajustes Avanzados.
    * En el Servidor Proxy indicamos la siguiente dirección: ssloth.nintendohomebrew.com
    * En el Puerto indicamos 8080
    * Guardamos y Realizamos la prueba de Conexión \[la prueba debe de tener éxito, de lo contrario repasar la dirección, el puerto o la Versión de consola]
    * Apagamos la consola.

    **PASO 3. EJECUTAR EXPLOIT**

    * Acudiremos al Modo Recovery pulsando: L + R + A + Cruceta superior (y Power una vez)
    * Cuando pregunte si deseamos Actualizar le damos a Aceptar.
    * La actualización fallará, es parte del proceso.
    * Le daremos a aceptar y saltará el instalador del Boot9, haremos la combinación de flechas para instalarlo.
    * Al finalizar estaremos en el Godmode9
2.  **PASO 4. INSTALAR SCRIPTS** Dentro del Godmode9:

    * Pulsaremos el botón Home
    * Acudiremos a la opción MORE, y después Scripts...
    * Ejecutaremos el Script PASO 1 Methax Retro (al finalizar la consola se reiniciará de nuevo al Godmode9)
    * Tras el reinicio, si nos pregunta si deseamos configurar una "Hora predeterminada" pulsaremos \[B]
    * Una vez dentro, pulsaremos el botón Home
    * Acudiremos a la opción Scripts...
    * Ejecutaremos el scripts PASO 2 ACT3DS
    * Terminado el proceso, la consola reiniciará Si saliera el panel de Luma, se debe verificar tener la 3ª opción marcada (Mostrar Nand o texto...) y el Splash de seguridad en Antes o Después. Darle al botón Start para salir del menú y reiniciar.

    **PASO 5. RECUPERAR RED**

    * Acudir a Configuración de la consola
    * Configuración de Internet / Conexión a Internet / Borrar conexión
    * Configuramos una nueva conexión

    **Ya tendremos la consola modificada y con el FBI inyectado** Para Finalizar, **tras cualquier proceso de hackeo se debe realizar el Respaldo NAND** ⁠📕nand-3ds
