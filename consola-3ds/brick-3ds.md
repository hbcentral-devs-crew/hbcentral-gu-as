# 📑 Brick 3Ds

### SEMIBRICK

LED EN CFW SEGURO 1.2

1. La consola no enciende.
2. NO se puede acceder a Luma ni a Godmode9.
3. No se mostrará el Splash de Seguridad.

LED EN CFW DEFECTUOSO 1.4

* Led BLANCO: No se reconoce el boot.fim ni en la Sd ni en el Ctrnand.
* Led MORADO: Solo se pudo reconocer el boot.firm del Ctrnand pero está dañado.
* Led ROJO: Se puedo reconocer el boot.firm en la Sd y en el CTrnand pero están dañados.

Video-Solución

{% embed url="https://www.youtube.com/watch?t=7s&v=hLOX5KFWUe8" %}

**ARRANQUE ROTO / LUMABUG**

1. La consola enciende pero no muestra imagen.
2. El led azul se mantiene encendido.
3. Sí se mostrará el Splash de Seguridad.

**SOLUCIÓN:**

1. Quitar el cartucho de juego o R4 que se tuviera y probar su inicio.
2. Esperar al rededor de 15 minutos con la consola encendida.

Video-Solución

{% embed url="https://www.youtube.com/watch?t=7s&v=fuD5KKXFkmY" %}

**BRICK NEGRO/ BLACK SCREEN**

1. La consola enciende pero no muestra imagen.
2. El led azul se mantiene encendido.
3. No se mostrará el Splash de Seguridad.

Video-Solución

{% embed url="https://www.youtube.com/watch?t=209s&v=OA74PsM7tNI" %}

**BRICK AZUL / ERROR BOOTROM**

1. El led azul se mantiene encendido.
2. NO se puede acceder a Luma ni a Godmode9.
3. No se mostrará el Splash de Seguridad.

Video-Solución

{% embed url="https://www.youtube.com/watch?t=193s&v=x64mBqRQ7Ss" %}

**BRICK FLEX / HARD BRICK**

1. La consola no enciende.
2. El led azul se apaga a los segundos.
3. NO se puede acceder a Luma ni a Godmode9.
4. En ocasiones se escucha un "pof" o pertardeo metálico.
5. Depende del fallo puede o no mostrar el Splash de Seguridad.

**SOLUCIÓN:**

1. **Llevarla a un técnico** para que repare la conexión del Flex.
