# 📕 Movable Format

{% embed url="https://www.youtube.com/watch?t=2s&v=Xe6qoIRUJao" %}

MOVABLE FORMAT.GM9

* El script **permite Restablecer la Consola de Fábrica desde el Godmode9.**
* En ocasiones es útil para reparar error ⁠📕arm9, el ⁠📕ctrnand-load y el ⁠📕arm11-core1 en el arranque de la consola.

Tiente dos variantes de instalación:

* **Formatear con Movable Original de Consola**
* **Formatear con Movable Donante**:
* **DONANTE ALFA** \[Para consolas **CON MOVABLE PREVIO**]
* **DONANTE BETA** \[Para consolas **SIN MOVABLE PREVIO**]
