# 📕 Errores FBI

ERROR FS (17)

**OCURRE PORQUE**

* La Sd está llena.
* La Sd no admite el archivo (quizás por estar con "Protección contra escritura").
* La Sd no es capaz de reconocer el archivo, aunque este exista.
* El ⁠⏳fbi-v2-6-1 no está actualizado a la versíon 2.6 o superiores.
* El ⁠⏳fbi-v2-6-1 no está inyectado en Salud y Seguridad y no es capaz de encontrar la ruta.
* Las rutas de instalación están corruptas.

**SOLUCIÓN**

* Tener el ⁠⏳fbi-v2-6-1 actualizado e inyectado en la app Salud y Seguridad.
* Probar con otras tarjetas Sd o vaciar algo de su contenido.
* Utiizar el programa ⁠📒hddllf-sd-protegida para eliminar la "Protección contra escritura".
* Aplicar el respaldo ⁠📕nand-3ds o el ⁠📕ctrnand-v1 para restablecer las rutas.

ERROR CAM (11) 0 (20)&#x20;

**OCURRE PORQUE**

* La cámara se ha desconectado al intentar escanear un código Qr. (20)
* La cámara está rota, a nivel de software o hardware. (11)

**SOLUCIÓN**

* Restablecer el ⁠📕ctrnand-v1 para comprobar si el error de cámara es de software. Si sigue fallando, podría ser un error de Hardware.
* Probar con otros métodos de instalación manual (no remotos).

1.  ERROR AM (32)**OCURRE PORQUE**

    * El Cia es inválido, está corrupto o no se puede instalar en la ruta.
    * El Cia no es de la misma Región que la consola.
    * El ⁠⏳fbi-v2-6-1 no está actualizado a la versíon 2.6 o superiores.
    * El ⁠⏳fbi-v2-6-1 no está inyectado en Salud y Seguridad y no es capaz de encontrar la ruta.

    **SOLUCIÓN**

    * Tener el ⁠⏳fbi-v2-6-1 actualizado e inyectado en la app Salud y Seguridad.
    * Probar con otro .cia del mismo título correspondiente a la Región de la consola o, en su defecto, Región Free/Libre.

2.  ERROR HTTP (40) o (254)\
    **OCURRE PORQUE**

    * El servidor web que se está utilizando no tiene el archivo.
    * El servidor web que se está utilizando ha interrumpido la comunicación.

    **SOLUCIÓN**

    * Probar con otros servidores web.
    * Probar con otros métodos de instalación manual (no remotos).

    ![ERROR HTTP (40) o (254)](https://images-ext-1.discordapp.net/external/0jj3FaF3uZ77szVPTY9ex2-t0hHUgQidFintE8IoO_g/https/cdn-longterm.mee6.xyz/plugins/embeds/images/733125364745896039/aa9a88e2cc30d0235c31fc4997a74d373d9e5dd7a713fd4e5f406127e1d7ad57.png?format=webp\&quality=lossless\&width=400\&height=225)
3.  ERROR APPLET (51)\
    **OCURRE PORQUE**

    * El ⁠⏳fbi-v2-6-1 es incapaz de ejecutar un juego dentro de su lista de títulos.
    * El Home puede ejecutar el juego pero esté termina lanzando ⁠📕arm11-core0 o ⁠📕arm11-core1

    **SOLUCIÓN**

    * Probar con otro .cia del mismo título correspondiente a la Región de la consola o, en su defecto, Región Free/Libre.
