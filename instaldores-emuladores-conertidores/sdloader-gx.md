# ⏳ SDLOADER-GX

{% embed url="https://www.youtube.com/watch?t=152s&v=GhKYWo8In6Y" %}

SDLOADER-GX - INSTALADOR DE CIAS\
El script **permite Instalar Cias desde Godmode9**&#x20;

Tiene dos variantes:

* MANUAL -> Se selecciona y se instala el .Cia que escojamos pudiendo luego eliminarlo.
* AUTOMÁTICA-> Se instalan y se eliminan todos los .Cia que se encuentren en la Carpeta GX.

**SDLOADER-GX SE CONVIERTE EN UNA FORMA SEGURA DE INSTALACIÓN**.

* No instala archivos corruptos
* No fuerza la consola (porque accede a las rutas directamente)
