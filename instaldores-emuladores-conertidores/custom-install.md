# ⏳ Custom Install

{% embed url="https://www.youtube.com/watch?t=5s&v=DQYGKD9zpxM" %}

CUSTOM - INSTALADOR DE CIAS\
El script **permite obtener los siguientes archivos para instalar Cias desde la SD**:\


* BOOT9.BIN
* SEEDDB.BIN
* MOVABLE.SED

**CUSTOM SE CONVIERTE EN UNA FORMA SEGURA DE INSTALACIÓN**.

* No instala archivos corruptos
* No fuerza la consola (porque no la usa)
* La velocidad de instalción depende del procesador del Pc.
